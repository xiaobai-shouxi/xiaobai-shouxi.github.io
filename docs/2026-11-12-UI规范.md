# 小白收息界面规范

工具页，深色。招财猫和金色是品牌，页面本身按「先看数字、再看明细」排。下面是现在代码里已经在用的约定。

## 颜色

定义在 `index.html` 的 `:root`。

| 用途 | 值 |
| --- | --- |
| 页面底 | `#070b16` |
| 卡片 | `#131c30`，内层 `#0e1626` |
| 正文 | `#eef2fb` |
| 次要文字 | `#93a4c3` |
| 辅助文字 | `#8496b5`，用在表头、代号、说明 |
| 涨 | `#f87171` |
| 跌 | `#34d399` |
| 主按钮 | 绿 `#34d399` → `#10b981`，字 `#04241a` |
| 品牌金 | `#facc15`，用在预计年息和总览 |

涨红跌绿，全站同一套。每个页面有自己的强调色，只涂在当前导航、图标和本页重点数字上，不要给每一列都上色。

## 字号

只用整档：11、12、13、14。再往上是区块标题 17、页标题 28、总览大数字 34（手机 32）。

- 11：标签、角标、手机底栏
- 12：说明、表内次行
- 13：按钮、表头说明、列表正文
- 14：区块标题、主按钮

金额和数量用 `tabular-nums`，表格里右对齐。名称左对齐。

## 间距和圆角

- 间距：8、10、12、16、20、26
- 卡片圆角 14，大面板 18，小控件 12
- 药丸按钮和账户切换是全圆角
- 相关内容靠紧，区块之间留 16

## 导航

桌面侧栏列出全部入口：收息总览、我的持仓、分红日历、收息统计、红利股票池、个股分红档案、跨境估值、展望未来、息覆生活、投资规则、设置与数据。侧栏比屏幕高时，侧栏自己滚动。

手机底栏只留前四项加「更多」，五项等分，文字 11px，栏高 56px，再加底部安全区。底栏在文档流里，不盖住上面的内容；内容在底栏上方单独滚动。

## 总览和持仓

- 没有持仓时，总览只写「还没有持仓」和两个动作，不先放 ¥0.00。空账户这一行只写「0 只持仓」，不带预计年息 ¥0.00。
- 有持仓时，桌面顶栏留一个「添加持仓」。页面里的重复主按钮收起，截图导入用线框按钮。手机顶栏是图标，页面里仍显示「添加持仓」。
- 进度条上面是已到账和完成比例，下面一行写比较和时间进度。
- 持仓表在提醒前面。提醒收成一行，点开展开。股票池没加载时，这一行直接去打开股票池。
- 表头用短名：每股分红、股息率。现价在大字，成本在小字，问号里保留口径说明。
- 手机持仓是卡片。第一张卡要完整出现在底栏之上。

## 状态

- 主按钮有悬停变亮、按下下移、键盘焦点环。
- 禁用是 55% 透明度。
- 示例持仓用提示条标明，并提供清空。
